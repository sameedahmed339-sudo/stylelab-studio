# Print design assets

Drop artwork here at the paths referenced by each entry's `image` field
in `lib/prints-catalog.ts`:

- sabar-ka-phal.png
- sukoon.png
- scorpio-dark-energy.png
- abba-nahi-maan-rahe.png

Transparent PNGs (at least 800x1000px) work best for the on-canvas
preview. Adding a new design later is a one-line addition to the
`printsCatalog` array — no other code changes needed, and if it's a new
category, a tab for it appears in the catalog UI automatically.
